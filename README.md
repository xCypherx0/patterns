## Модель расчета

Снаряд рассматривается как материальная точка под действием силы тяжести и силы лобового
сопротивления воздуха F = 0,5·ρ·Cx·S·v². Уравнения движения интегрируются численно с шагом 0,01 с,
результатом являются время полета, дальность, наибольшая высота и скорость в точке падения.

## Сборка и запуск

Нужен JDK 17 или новее. Пример для первой лабораторной (для остальных меняется номер):

```
cd lab1
javac -encoding UTF-8 -d out src/lab1/*.java
java -Dfile.encoding=UTF-8 -cp out lab1.Main
```

В консоли Windows перед запуском выполните `chcp 65001`, чтобы русский текст отображался корректно.
