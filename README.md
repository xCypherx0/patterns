## Модель расчета

Снаряд рассматривается как материальная точка под действием силы тяжести и силы лобового
сопротивления воздуха F = 0,5·ρ·Cx·S·v². Уравнения движения интегрируются численно с шагом 0,01 с,
результатом являются время полета, дальность, наибольшая высота и скорость в точке падения.

## Сборка и запуск

Нужен JDK 17 или новее. Пример для первой лабораторной (для остальных меняется номер):

```
cd lab1
javac -encoding UTF-8 -d out src/lab1/*.java
java -Dfile.encoding=UTF-8 -cp out lab1.Main
```

В консоли Windows перед запуском выполните `chcp 65001`, чтобы русский текст отображался корректно.


## Демонстрация лабораторных 9-15

В Windows откройте файл `Запустить_лабы_9-15.cmd` двойным щелчком.
Он соберет исходники и откроет общее окно с семью вкладками.
На каждой вкладке показан фактический вывод метода main соответствующей лабы.
Нужен установленный JDK 17 или новее с командами java и javac в PATH.

В VS Code откройте папку проекта, установите Extension Pack for Java,
выполните Developer: Reload Window и откройте панель Run and Debug (Ctrl+Shift+D).
Выберите «Лаба 9» ... «Лаба 15» и нажмите F5.
Вывод появится в Debug Console. Для общего окна можно запустить `demo/src/demo/DemoRunner.java`.

Сборка отдельной новой лабы из корня проекта, пример PowerShell:

```powershell
javac --release 17 -encoding UTF-8 -d lab9/out lab9/src/lab9/*.java
java '-Dfile.encoding=UTF-8' '-Dsun.stdout.encoding=UTF-8' -cp lab9/out lab9.Main
```

В работе 13 используется локальная модель недоступного сервиса и управляемые часы.
Это демонстрация Circuit Breaker без сети и развертывания микросервисов.
В работе 14 журнал сохраняется в journal.csv в текущей папке запуска и остается после завершения. При запуске профиля VS Code или общей демонстрации файл находится в корне проекта. Повторный запуск обновляет демонстрационные записи с теми же идентификаторами.
В работе 15 распределение задач между потоками может меняться при каждом запуске.
